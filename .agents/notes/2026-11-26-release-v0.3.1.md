# Agent Note: Release v0.3.1 —— 修复浏览器产物误打入 Host 模块

Status: implemented

## Decision

- 将 `dsh-cwtools` 发布为 `0.3.1`，修复 issue #1：`0.3.0` 的 `lib/client.js` 内联了 `cwtools-shared` 的 Host 模块并 `require` Node 内置模块，DSH 客户端加载失败，设置分区不出现。
- 依赖升级到 `cwtools-shared@0.5.0`（新增浏览器安全的 `./catalog` 子路径导出）与 `cwtools-node@0.3.1`（仅对齐 shared 依赖，避免安装两份 shared）。理由见 `implemented/architecture/2026-11-10-shared-tool-catalog.md`。
- `build` 增加 `check:client-bundle`，浏览器产物出现 Node 内置模块请求即失败；`prepack` 经由 `build` 同样受此约束。
- `pnpm-workspace.yaml` 仅为这两个新版本扩展 `minimumReleaseAgeExclude`。

## Verification

- 发布前用本地打包的 `cwtools-shared-0.5.0.tgz` 预检：构建、bundle 检查与 81 项测试通过。
- 发布后基于 npm 上的正式版本重新执行 `pnpm install`、`pnpm run build`、`pnpm test`、`npm pack --dry-run` 与 `git diff --check`。
